# Producer Agent 使用指南

## 🎯 什么是 Producer Agent？

Producer Agent 是 drama-team 的**制作人**，负责统筹管理整个创作团队。

就像真正的影视剧制作人一样，它会：
- 📋 制定创作计划
- 🎬 调度 Writer/Aligner/Recorder Agent
- 📊 监控进度和质量
- ⚠️ 处理问题和异常
- 📢 定期向用户汇报

---

## 🚀 快速开始

### 方式 1: 使用启动脚本

```bash
# 进入项目目录
cd ${OPENCLAW_WORKSPACE_DIR}/suspense-drama

# 启动制作人
node ${OPENCLAW_WORKSPACE_DIR}/skills/drama-team/scripts/drama_producer.js .
```

### 方式 2: 在 OpenClaw 中启动

```
启动 drama-team 制作人，自动完成《午夜来电》创作
```

### 方式 3: 手动调用 sessions_spawn

```javascript
sessions_spawn({
  runtime: "subagent",
  mode: "session",  // 持续运行
  task: `你是 Drama Team 的 Producer Agent。
         请统筹管理《午夜来电》的创作工作。
         自动调度 Writer/Aligner/Recorder Agent，
         定期汇报进度，遇到问题主动提醒。`,
  cwd: "/path/to/suspense-drama"
})
```

## ⚙️ 配置选项

Producer 可以配置：

```yaml
producer:
  auto_mode: true              # 自动模式
  report_interval: 5           # 每 5 集汇报一次
  max_iterations: 5            # 最大迭代次数
  quality_threshold: 4.0       # 质量阈值
  milestone_points: [25, 50, 75, 100]  # 里程碑节点
```

## 🎯 Producer vs 手动管理

| 功能 | 手动管理 | Producer 管理 |
|------|---------|--------------|
| 启动方式 | 每集手动启动 | 一键启动全部 |
| 主会话占用 | 需要时刻监控 | 解放，可做其他事 |
| 进度追踪 | 手动查询 | 自动汇报 |
| 问题处理 | 手动发现 | 主动提醒 |
| 效率 | 低 | 高 |
| 适用场景 | 单集创作 | 批量创作 |

---

## 📝 最佳实践

### 推荐使用场景

✅ **批量创作**：需要创作多集剧本
✅ **长期项目**：24集、48集等长剧
✅ **解放主会话**：不想时刻盯着进度
✅ **自动化需求**：希望自动完成

### 不推荐使用场景

❌ **单集创作**：只创作 1-2 集
❌ **需要精细控制**：每集都要人工审核
❌ **测试阶段**：还在测试 skill 功能

# Storyboard 批量生成实战模式

> 2026-05-15 Carmilla v2 项目验证（EP-01 ~ EP-17 连续生成，全部 91-95 分 PASS）

## 核心结论

- **批量节奏**：用户确认"后面可以尝试2集或3集合一起去生成"。实践：2-3集合并生成是最佳批量粒度——单次输出 ~20-30K chars，主模型一次性输出不中断。
- **主模型逐集写（write_file）是唯一可行方案**——本地 API 超时、子代理 context 不够。
- **每集必须内联 Storyboard-Aligner 自审**——不可跳过，自审本身就是质量保障。

## 每集分镜固定结构（不可省略）

```
1. Episode Info（总场景数/集天气/BGM主线/转场音效）
2. Key Frames 表格（12列：# / Time / Scene / Shot / Camera / Duration / Description / Characters / Atmosphere / Lighting / SFX / BGM）
3. Shot Notes（9项必填：节奏分层/运镜匹配/景别层次/时空切换/灯光设计/音效设计/音乐弧线/AI指令颗粒度/情绪递进/运镜种类统计）
4. Storyboard-Aligner Self-Review（集类型判断 + 6维度评分表 + 修改建议）
```

## 高质量 Storyboard 的共性模式

### 1. 节奏分层：张弛对比必须明确

每个集必须有"快速段"和"慢速段"的对比：
- **快速段**：3-4s/镜，用于对峙/动作/恐惧
- **慢速段**：5-7s/镜，用于关键信息(日记/照片)、情感转折、悬念留白
- **张弛公式**：快速(3-4s) → 慢(5-7s) → 爆发(3s) → 静默(2-3s)

### 2. 运镜种类 ≥ 8种

高质量集的运镜统计：正面/侧面/背面/低角度/仰拍/俯拍/微距/手持/推/拉/缓推/固定
- **少于5种** → 视觉疲劳，扣分
- **≥8种** → 画面丰富，PASS 概率高

### 3. 景别五层混合

| 景别 | 用途 | 占比建议 |
|------|------|---------|
| 极端特写 | 关键道具/文字/表情细节 | 5-10% |
| 特写 | 表情/紫纹/照片 | 25-35% |
| 近景 | 对话/反应/独处 | 30-40% |
| 中景 | 动作/转场/建立关系 | 15-25% |
| 全景 | 开场定场/收尾空间关系 | 5-10% |

### 4. 灯光三层写法（每次都写满）

```
主光(来源,颜色,方向) + 补光(来源,颜色,方向) + 效果(暗角/自发光/轮廓光)
```

**常见组合**：
- 夜晚室内：月光(窗冷蓝主)+烛光/台灯(暖黄补)+暗角
- 白天室外：阳光(暖白主)+树叶光斑/建筑阴影(补)+发丝光
- 恐怖场景：闪电(间歇冷白爆发)+自发光(深紫/暗红)+暗角压暗

### 5. 音乐弧线必须有起承转合

每个集的音乐不能平铺直叙，必须有：
```
起(铺垫) → 承(渐强) → 转(骤停/爆发/转调) → 合(收尾/低频)
```

### 6. Shot Notes 9项不可省略

每项 Shot Note 提供 AI 审核的判定依据。省略任何一项都会导致 Aligner 评分时缺少参考。

## 批量生成工作流（推荐）

```
Phase 1: 读 2-3 集剧本（read_file 并行）
Phase 2: 主模型分析每集：场景数/角色/集类型/节奏/镜头数
Phase 3: 逐集写分镜（write_file），每集包含完整的 12列表格 + Shot Notes + Aligner 自审
Phase 4: 如果 2-3 集内容量大 → 合并为一个 write_file 调用（20-30K chars 不中断）
         写完后用脚本拆分成独立文件（如 EP-15/16/17 合并写入后拆分）
Phase 5: 下一批
```

## 常见扣分项（实战统计）

| 扣分项 | 典型分值 | 出现频率 |
|--------|---------|---------|
| 近景过多，缺少全景建立 | -2/集 | 高频（几乎每集都有） |
| 缺少AI约束词 | -1/集 | 高频 |
| 运镜可以更动态 | -1/集 | 中频 |
| 转场镜头可以更短 | -1/集 | 低频 |

**修正策略**：扣分项是 Style Notes 级别的，不影响 PASS。每集在修改建议中标注即可，不用重写。

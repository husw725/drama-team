# v2.2 场景/道具 Reference 数据迁移工作流

适用于：任意短剧项目从旧格式（内嵌 `scene: [...]`）升级到 v2.2 场景/道具引用格式。

## 迁移步骤

### 1. 提取唯一场景
```python
# 遍历所有集 imagePrompts，用 scene: [...] 正则提取
# 前10个词作为去重 key
scene_text = re.search(r'scene:\s*\[(.*?)\]', prompt, re.DOTALL).group(1)
key = " ".join(scene_text.split()[:10])  # → "gothic victorian bedroom, cool candlel"
```

### 2. 写场景 Reference Prompt（纯环境）
- 格式：`风格 + 画幅 + wide establishing shot, no characters, environmental scene reference, 完整视觉描述`
- 每个唯一场景一个，全剧通常 10-15 个

### 3. 筛选关键道具
```python
# 关键词匹配统计频次
prop_keywords = {"purple_mark": [...], "diary": [...], ...}
# 出现 ≥3 次的作为关键道具（龙套道具不需要）
```

### 4. 写道具 Reference Prompt（静物特写）
- 格式：`风格 + close-up still life, no characters, prop reference, 形状材质颜色描述`
- 典型关键道具：日记、匕首、画像、特效（金色/紫色光/雾）等

### 5. 改造关键帧 Prompt
```python
# 用 scene text → S-XX ID 映射替换
new_prompt = re.sub(r'scene:\s*\[[^\]]*\]', '[ref: S-XX]', old_prompt, flags=re.DOTALL)

# 添加字段
shot["scene_ref"] = "S-XX"
shot["prop_refs"] = detect_props(prompt)  # → ["P-01", "P-03"]
```

### 6. 更新 project_data.json 结构
- 添加顶级 `scenes[]` 和 `props[]` 数组
- 每个元素：`{id, name, prompt, status: "pending"}`

### 7. 更新 build_html.py
- 添加场景管理 Tab（按钮 + 内容区 + JS 渲染函数）
- 添加道具管理 Tab
- `init()` 调用 `buildScenes()` 和 `buildProps()`
- `importJSON()` / `exportJSON()` 处理 scenes/props

### 常见坑
| 坑 | 解法 |
|----|------|
| scene text 去重不准 | 前 10 个词做 key，但需要手动验证 |
| 场景匹配失败 | 用 `extraction_map` 模式匹配（前 4 个词） |
| 道具关键词误匹配（如 "mirror" 匹配到 "antique mirror"）| 优先匹配更长的关键词 |
| videoPrompts 也需要改造 | 别忘了遍历 `videoPrompts` 数组 |
